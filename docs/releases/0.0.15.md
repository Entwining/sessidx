No reindex is needed: the schema and parser versions are unchanged.

`sessidx skill install` links `~/.claude/skills/sessidx` and `~/.agents/skills/sessidx`, which Claude Code, Codex, and Pi read, to the skill a Homebrew install includes, so the skill changes together with the binary on every upgrade. It replaces a link made as the 0.0.14 notes described, but refuses a copied skill directory: remove that copy, and any plugin or package install of the skill, first, or the agent finds two. `sessidx skill show` prints the skill this version ships. The skill's text is unchanged, so plugin and Pi installs need no update.
