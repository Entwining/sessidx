Nothing changes for callers. The binary is built from the same source as 0.0.2, so no `sessidx index --full` is needed.

The source tree now stages the whole package with `make build OUT=DIR`: the binary, `LICENSE`, `README.md`, and `LICENSE-THIRD-PARTY.md`, whose render fails on any cargo-about warning. The Homebrew formula switches to it after this release, so later packaging changes ship with the release that contains them.
