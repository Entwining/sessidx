No reindex is needed: the schema and parser versions are unchanged.

`sessidx skill install` now works when `~/.claude/skills` links to a `~/.agents/skills` that does not exist yet, as on a fresh machine whose dotfiles manage that link; 0.0.15 failed there and linked neither path. It also checks both paths before changing either, so refusing a copied skill at one path leaves the other alone, and its `end` record counts in the unit `skill_paths`, which replaces `skill_links`. The skill's text changed in one sentence that no lookup depends on, so updating a plugin install is optional.
