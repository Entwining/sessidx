First public release.

sessidx indexes local Claude Code, Codex, and Pi session logs into SQLite. `search`, `grep`, and `show` find past sessions and expand exact records; `count`, `sql`, and `doctor` count commands, failures, and denials with stated denominators. Every command prints JSON Lines ending in an `end` record that states completeness. Each query refreshes the index within a two-second budget, and raw logs are never modified.

Install on Apple Silicon macOS with `brew install entwining/tap/sessidx`, and give an agent the bundled skill with `gh skill install Entwining/sessidx sessidx --scope user`. The database stores redacted session text; the README lists what it contains and the limits of redaction.
