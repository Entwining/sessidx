Run `sessidx index --full` after upgrading. The schema version is now 10, and until the rebuild every command stops with `database schema changed; run sessidx index --full`.

Update the skill too. Claude Code does not update plugins from third-party marketplaces by default, so run `claude plugin update sessidx@entwining`, or enable auto-update for the `entwining` marketplace under `/plugin` as the README describes. Codex updates the plugin when it starts, and Pi updates with `pi update git:github.com/Entwining/sessidx`. The skill now describes paged output and tells agents not to shorten output themselves, because `head -c` or a slice drops the `end` record.

`search`, `grep`, and `show` pages now hold at most 24 KiB of data lines, so the `end` record stays within what Claude Code, Codex, and Pi show an agent from one command. A record that does not fit after others starts the next page. A `grep` or `show` record too large for a page alone carries `part`, a piece of its redacted JSON text, instead of `record`, and a `cut` entry with the whole text's `bytes` and the piece's `offset` and `kept` bytes; `show` continues the record through `next` until the joined pieces parse as the record. A `search` session that does not fit shortens its hit texts to one common length and names each in `cut` by JSON Pointer. Cursors from earlier releases are refused; restart the query without `--cursor`.

`canonical_events.text` for a Claude message now joins the text of every record Claude Code wrote for that response in the transcript. With extended thinking the first record holds only thinking, so the text was empty before; on the maintainer's logs from 2026-09-01 through 2026-10-12, Claude assistant messages with text rose from 3,453 to 12,378.

Denial reasons now come from each agent's own fields and from a reason marker, `[class:producer/reason]`, that any guard can put at the start of its refusal; sessidx no longer learns guard wording. `denials` gains `class` and `producer`, and `reason_id` holds the producer's own ID. A marker leading a failed Pi result or a bare Claude rendering is denial evidence by itself, with `source` `marker`. A marker that redaction would change keeps only its class. The table of historical guard sentences is frozen and applies only when no marker parsed.

Reason IDs now use snake_case public IDs, so update saved queries. Most are the snake_case form of the old name, such as `AppData` to `app_data`. These change more: `Broad` to `broad_scan`, `CodeFile` to `inline_credential_file`, `Dump` to `variable_dump`, `File` to `credential_file`, `GrepSsh` to `grep_ssh_private`, `Ssh` to `ssh_private`, `Launcher` to `claude_launcher`, `Server` to `dev_server`, `Token` to `git_hosting_token`, `Trace` to `curl_trace`, `Upload` to `credential_upload`, and `Variable` to `credential_variable`. `CoverageGap`, `CheckError`, and `Symlink` become `unknown` with class `coverage` or `error`.

Claude `toolDenialKind` is now mapped from the seven values Claude Code writes. `interrupted` and `cancelled` no longer record a denial, while the result still counts as failed; `automode-parsing-error` counts as `classifier_unavailable`; and a rejection Claude Code attributes to a hook gives the `hook` channel when no text rule recognized it.
