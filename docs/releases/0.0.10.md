Run `sessidx index --full` after upgrading. The schema version is now 14, and until the rebuild every command stops with `database schema changed; run sessidx index --full`. The rebuild ends by compacting the database, which needs free disk space up to twice its size while it runs.

Update the skill too. Claude Code does not update plugins from third-party marketplaces by default, so run `claude plugin update sessidx@entwining`, or enable auto-update for the `entwining` marketplace under `/plugin` as the README describes. Codex updates the plugin when it starts, and Pi updates with `pi update git:github.com/Entwining/sessidx`. The skill now describes the request columns and the `request_errors` view below, and tells agents never to divide request errors by `requests`.

Requests now keep the evidence their record states of where the agent sent them (#71). `requests` gains `route`, with the field it came from in `route_source`, and `stop_reason` in the agent's own words, and `request_passes` carries its request's route. A route says where a request went, not how it was billed, so `count usage` has no route grouping yet. The new `request_errors` view holds the records in which an agent states that a request failed: Claude Code's retried `api_error` attempts, the failures it reported with `isApiErrorMessage`, and Pi entries that stopped with `error`. They are reports rather than a part of `requests`, because a retried attempt can still end in a request, so an error rate does not divide them by `requests`. Codex records no request errors, so its failures stay uncovered. A Pi error's message is now indexed, so `search` finds the failure by what it said.

A Codex compaction now names the request that wrote it in `compactions.request_id`, and in a rollout that continues a compacted thread, that request is now counted in `count usage`. Short Pi tool-call IDs that repeat across or within sessions no longer merge different calls and their outcomes. In `count commands`, `sites_without_program` now also counts sites whose program redaction withheld.

Records that no rule reads are now passed over instead of being reported as unknown (#72). `end.refresh` drops `unknown_records`, and `doctor` drops `records_with_unknown_shape` and `unknown_shape_signatures`. Its `records` now counts indexed lines, so a stream that fails to decode counts in `parse_errors` but not in `records`. The `shapes` table is gone.
