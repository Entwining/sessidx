No reindex is needed: the schema and parser versions are unchanged.

A Homebrew install now includes the skill from the same release at `$(brew --prefix sessidx)/share/sessidx/skills/sessidx`, so the skill an agent reads from there changes together with the binary on every upgrade. To use it instead of a plugin or package install, remove that other copy and link this one into the skills directory the agent reads, as the README's "Homebrew's copy" section shows. The skill's text is unchanged, so plugin and Pi installs need no update.
