Claude Code does not update plugins from third-party marketplaces by default, so run `claude plugin update sessidx@entwining`, or enable auto-update for the `entwining` marketplace under `/plugin` as the README describes. Codex updates the plugin when it starts, and Pi updates with `pi update git:github.com/Entwining/sessidx`. The skill now tells agents to correlate `events` or `commands` with `sessions` per transcript by `file_id` or the indexed `path`, because `(agent, session_id)` can name several transcripts and combines their events.

Redaction now runs once, when a record is indexed, instead of again on the way out. `search`, `sql`, `count`, and `doctor` print what was stored: SQL cells and column names keep the stored text, session IDs are no longer blanked, and `doctor` signatures keep their structural prefix. An existing database keeps the redaction it was built with until `index --full` rebuilds it. Only raw source ranges (`show`, `grep`) and error text that can quote raw input are still redacted when printed.

A credential assignment now keeps its name and masks only the value, so the key stays searchable and JSON quoted inside text stays valid. Escaped name and value quotes with one backslash layer are now recognized, and Cookie and Set-Cookie headers mask their whole value through the line end or enclosing argument quote. A name is judged by its last word, after trailing words that name the value's form, so usage counters such as `input_tokens` keep their numbers while `api_key_value` is still masked. The same name test recognizes `cookie`, `cookies`, `sessionid` and `phpsessid`, so `cookies` arrays and `--cookie` values are masked; `session` and `sid` still need other credential context. Identifiers that entropy redaction used to destroy are now kept, including `x86_64-apple-darwin`, `path:line:column`, and `<uuid>.jsonl`.

Assignment-shaped arguments after a command name, such as `CC=clang` in `make CC=clang all` or `title=hello` in `gh api -f title=hello`, stay in `commands.argv_json` with their original spelling; an assignment before the command name still configures the environment and stays out. `sessions.path` is now a unique index, so joining on `path` no longer runs into the two-second `sql` limit.

Denial `reason_id` values now name the guard rule that printed them, using the identifier in the agent-guard source or the dotfiles name for a rule only those guards had, and historical guard sentences are classified too. A bare Pi refusal now counts as a guard denial only when its line starts with a published guard sentence. Six existing values were renamed: `Appdata` to `AppData`, `SecretPrint` to `StoredSecret`, `Syntax` to `UnsupportedShellSyntax`, `Replace` to `RgReplace`, `Include` to `RgInclude`, and `Bre` to `RgBre`, so update saved queries. On the maintainer's logs, denials with an unknown reason fell from 2,161 to 829 for Claude and from 105 to 7 for Codex, and the database grew by about 2%.
