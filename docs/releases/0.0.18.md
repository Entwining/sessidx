A `search` with filters that returns no session now says what the filters hid. Its `end` record carries `filtered_out`, as in `"filtered_out":{"sessions":4,"without":{"--cwd":4,"--since":0}}`: `sessions` is the number of sessions the terms match with no filter, and `without` gives, for each filter option passed, the number they match with only that option removed. A zero `sessions` means the terms match nothing, and a nonzero entry of `without` names an option whose removal returns sessions. Before, such a search ended with `complete=true` and nothing else, which read as absence when a `--cwd`, `--since`, or another filter had excluded every match.

`search` reports these counts and does not widen the search itself. They share the search's two-second limit and are left out when they run out of it, so a result without `filtered_out` does not show that no filter hid a match. Only a first page carries them.
